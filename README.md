# RetireFire: CPO Supply Chain Intelligence

This project tracks the Co-Packaged Optics (CPO) and Silicon Photonics (SiPh) supply chain to identify high-alpha investment opportunities in the AI infrastructure build-out.

## Core Assets
- **GIGACPO Terminal**: [terminal_v2_panel.html](terminal_v2_panel.html) (V4.7 High-Density Intelligence)
- **Master Dataset**: [database/CPO_MASTER_DATA.json](database/CPO_MASTER_DATA.json)
- **Intelligence Base**: [KNOWLEDGE.md](KNOWLEDGE.md)
- **Hardened Rules**: [.agent/skills/](.agent/skills/)

## LLM Brain (Shared Intelligence)
To share the entire ecosystem with another LLM (Grok/Claude), use the files in:
- `database/CPO_BRAIN.json` (Structured Data)
- `database/CPO_BRAIN.md` (Technical context)

## Visuals & Infographics
Visual maps of the supply chain are automatically generated into the **`/infographs`** folder. 

## Maintenance & Audits
To keep the AI's logic strictly aligned with the project's evolving needs, run:
- `/production-code-audit`: Performs enterprise-grade security and performance hardening.
- `/project-skill-audit`: Analyzes patterns to update Agent Skills and project governance.
- `/update`: Synchronizes all documentation with the latest code state.

To refresh everything, run `start.bat` option 2.
